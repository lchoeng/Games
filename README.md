# Games

Family games, one folder per game. Open a game's `index.html` in a browser to play.

| Game | Folder | Description |
|---|---|---|
| Linus: Dinosaur Devourer | [`linus-dinosaur-devourer/`](linus-dinosaur-devourer/) | Kirby-style platformer. Inhale dinosaurs, copy their powers, beat six bosses across six worlds. |
| Jaiden: Dinosaur Devourer | [`jaiden-dinosaur-devourer/`](jaiden-dinosaur-devourer/) | The same game starring Jaiden, with its own saved progress. |
| Homie Fighters 2 | [`homie-fighters-2/`](homie-fighters-2/) | Street Fighter–style brawler with seven homies, each with a special attack and a projectile. |
| Dragon Eater | [`dragon-eater/`](dragon-eater/) | Snake-style eat-and-grow game. Linus starts as a baby dragon, evolves through five stages across six worlds, and eats the Dragon King. |
